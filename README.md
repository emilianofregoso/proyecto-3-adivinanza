# Proyecto 3: Juego de adivinanza

## Descripción
Este programa es un juego de adivinanza hecho en Python. Genera un número aleatorio del 1 al 100 y el jugador tiene siete intentos para adivinarlo. En cada intento, el programa indica si el número secreto es mayor o menor.

## Objetivo
Practicar el uso de entradas, salidas y estructuras de control en Python.

## Cómo ejecutar
1. Abre el archivo `main.py`.
2. Ejecuta el programa en Python 3.

## Estructuras utilizadas
- `input()`: recibe el número que escribe el jugador.
- `print()`: muestra instrucciones, pistas y resultados.
- `if`, `elif` y `else`: comparan los números y muestran las pistas.
- `while`: repite los intentos hasta acertar o quedarse sin oportunidades.
- `random.randint()`: genera el número secreto.

## Archivos
- `main.py`: contiene el código del juego.
- `capturas/`: contendrá las capturas de evidencia de la ejecución.
